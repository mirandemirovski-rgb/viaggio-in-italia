# Viaggio in Italia

**Impara l'italiano attraversando l'Italia, città dopo città, con Orfeo.**

A real Italian course, levels A1 to B1 of the Common European Framework of Reference for Languages (CEFR), told as a journey across an old map of Italy. Each city is a complete lesson unit; some cities are tests.

Live site: https://mirandemirovski-rgb.github.io/viaggio-in-italia/

## How it is built

- Plain HTML, CSS and JavaScript. No build step. Served by GitHub Pages.
- `assets/js/map.js` draws the map; `places.js` holds every place, curiosity and hidden message; `glyphs.js` holds the ink drawings.
- `assets/js/geo.js` is generated by `tools/make-geo.mjs` from Natural Earth data (public domain).
- Fonts: IM Fell English and EB Garamond (SIL Open Font License, see `assets/fonts`).

## Sources for the lessons

Lessons follow the CEFR level descriptors, the reference syllabi of the Italian certification bodies (CILS, CELI, PLIDA, CERT.IT) and the unit-by-unit progression of widely used coursebooks such as *Nuovo Espresso* (ALMA Edizioni) and *Nuovissimo Progetto italiano* (Edilingua). All dialogues, exercises and stories are original. This is an independent project, not affiliated with those publishers or institutions.
